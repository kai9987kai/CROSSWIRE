# CROSSWIRE priority roadmap

The user's order is the implementation order. The table records implemented capabilities and their validation scope; library utilities, integrated runtime workflows, local checks and hosted CI execution are distinct. Current follow-through is recorded in [the budgeted experiments verification report](verification-budgeted-experiments.md).

## Evidence policy

The factored solver is selectable in run, study, CLI and workbench workflows via `candidate_backend`; flat remains the default. Backend telemetry records the actual implementation, factor counts and cached storage before deployment/private audit. Structural ratios are not measured memory compression, and public checking/private audit remain exhaustive. Soft-return synthesis is integrated into the runtime shield via `recovery_strategy="soft_return"`, executing multi-step certified return paths when anomalies or hazards occur. Hosted CI results belong to their recorded commit; configuration alone is not evidence of a successful run.

The 2026-10-30 increment adds controlled fault settings to studies and the workbench, canonical fault-condition analysis, phase-correct private audits, composable sensor/semantic faults, report digest validation and isolated installed-wheel checks. Historical receipt bytes remain unchanged; newly named evidence records this source revision.

The 2026-11-01 increment adds independently checked bounded experiment trees, actual factored runtime selection, product-state robust planning, exact class-histogram task scoring and backend-separated study conditions. Research basis, controls, results and validation are recorded in `research/2026-11-01-budgeted-experiments.md` and `docs/verification-budgeted-experiments.md`. Search limits remain unknown/incomplete results; this work does not establish a new theorem or general safety.

The 2026-11-03 increment adds:
1. Certified soft return-to-home dispatch in runtime shielding (`recovery_strategy="soft_return"`), synthesizing and executing multi-step return trajectories to $q_0$ while preserving live belief filtering.
2. Decision-theoretic Value of Information (`voi`) active probing policy maximizing expected posterior task readiness with Shannon entropy tie-breaking.
3. Information-theoretic surprisal bits and mean symbol loss tracking in model diagnostics certificates.
4. Interactive dashboard support for VoI probing, recovery strategy selection, and soft return telemetry.
5. Sequential non-conformity test martingales and anytime-valid e-processes ($M_t = \prod_{k=1}^t E_k$) with finite-sample Type-I error control under Ville's maximal inequality ($\mathbb{P}_{H_0}(\exists t \ge 1: M_t \ge 1/lpha) \le lpha$), refuting misspecified model classes at $lpha=0.05$ and $lpha=0.01$.
6. Publication-grade formal LaTeX conference paper (`paper/crosswire_formal_synthesis.tex` and `paper/references.bib`) verified by automated structural/citation checker (`tools/check_latex.py` and `tests/test_paper.py`).

Keep implementation, local validation, independent target sampling, CI execution and publication distinct. Preserve historical receipt bytes and their source revisions. Never count label seeds or duplicate implementations as independent dynamics. Zero observed hazards must not produce a zero-width safety claim.
