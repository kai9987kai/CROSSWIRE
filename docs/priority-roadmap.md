# CROSSWIRE priority roadmap

The user's order is the implementation order. The table records implemented capabilities and their validation scope; library utilities, integrated runtime workflows, local checks and hosted CI execution are distinct. Current follow-through is recorded in [the resilience workflow verification report](verification-resilience-workflows.md).

| Priority | Milestone | Current phase and completion criterion |
|---|---|---|
| 1 | Safe calibration and active probing | Completed: eight-policy pre-query guard (`probe_safety="model_safe"`); retains regression tests for long witnesses, interrupted attempts, no-safe-action abstention and temporal escalation. Guarantees remain model conditional. |
| 2 | Risk configuration and certification | Completed: CLI/API/UI tolerance and independent fraction checks (`risk_controlled` mode); retains malformed-input and strict-boundary tests. Candidate fractions are not calibrated real-world risk. |
| 3 | Uncertainty and model mismatch | Completed: sequential forecasts before observing each output, first refutation witnesses, deterministic-reset conflicts, enabled-class diagnostics, and explicit semantic blind spots. Compatibility leaves inclusion UNKNOWN. |
| 4 | Statistical reliability | Completed: versioned generated protocol dynamics (`generated_protocol`), separate structural `instance_seed`, nuisance-aware parent grouping and conservative finite-sample intervals (`crosswire/reliability.py`). Verified with a 128-run independent-instance pilot (`reports/pilot-independent-protocols-receipt.json`). |
| 5 | Adaptive branching calibration | Completed: interactive within-query action selection (`policy="branching"`); evaluates conditional predictive entropy and model safety under surviving belief at every action dispatch; halts early upon contract readiness; verified with 10 unit tests in `tests/test_branching_calibration.py`. |
| 6 | Online replanning and recovery | Completed: explicit change-point fault schedules (`RunConfig.fault_schedule`) supporting 5 runtime fault types (`sensor_drift`, `actuator_swap`, `delay_spike`, `stuck_output`, `semantic_swap`); exact detection latency measurement ($\Delta t = t_{\text{detect}} - t_{\text{fault}}$); causal hazard aversion tracking for both shielded halts and online replanned safe detours; epistemological negative control verification (`semantic_swap` undetectable by black-box monitors, verified hazardous by private semantic audit). Verified with 7 tests in `tests/test_change_points.py`. |
| 7 | Scale beyond enumeration | Completed: `FactoredCandidateSpace` decomposing the hypothesis space into orthogonal factor spaces $\mathcal{P}_I \times \mathcal{P}_O$ with lazy adapter generation, proxy indexing, and full `CandidateSpace` method parity; semantic evaluations, `probe_is_safe`, `robust`, and `risk_controlled` planning operate on active input factors $\mathcal{I}_{\text{surv}}$ in $O(|\mathcal{I}_{\text{surv}}|)$ time; anchors prune $\mathcal{P}_O$ independently in $O(N_O \cdot \|\text{anchors}\|)$ time; sub-second pruning and symbolic safety verification demonstrated on 17,280 candidate models. Verified in `tests/test_factored_space.py`. |
| 8 | Realistic benchmarks | Completed: added realistic robotics and stateful protocol conformance benchmark families (`robotics_airlock` 5-state dual-door interlock controller and `protocol_session` 6-state `SYN -> AUTH -> OPEN -> COMMIT` session controller) with independently authored table and procedural engines, zero-hazard `model_safe` calibration without anchors, out-of-horizon 4-step synthesis, and change-point fault injection. Verified with 7 tests in `tests/test_realistic_benchmarks.py`. |
| 9 | Dashboard | Completed: workbench UI (`crosswire/web/index.html`, `crosswire/web/app.js`) exposes model inclusion, forecast timelines, structural target seeds, reliability denominators, `branching` active calibration, `robotics_airlock` and `protocol_session` benchmarks, factored hypothesis space compression (`active_input_factors × active_output_factors`), and change-point fault detection latency ($\Delta t$) telemetry. Verified via headless Playwright Chromium (`tools/check_workbench.cjs`). |
| 10 | CI and reproducible releases | Completed: Dual-OS GitHub Actions workflow (`.github/workflows/ci.yml`) on Ubuntu and Windows across Python 3.11 and 3.12, testing automated suite, clean wheel build and install, scientific receipt replay, and headless Playwright Chromium workbench checks. |

## Evidence policy

The factored solver and soft-return synthesizer are currently library utilities tested directly. Run, study and CLI acquisition still use `CandidateSpace`; dashboard factor counts describe candidate structure, not measured factored-backend compression. Soft-return synthesis is not dispatched by the runtime shield. The CI matrix is configured; configuration alone is not evidence of a successful hosted run.

The 2026-10-30 increment adds controlled fault settings to studies and the workbench, canonical fault-condition analysis, phase-correct private audits, composable sensor/semantic faults, report digest validation and isolated installed-wheel checks. Historical receipt bytes remain unchanged; newly named evidence records this source revision.

Keep implementation, local validation, independent target sampling, CI execution and publication distinct. Preserve historical receipt bytes and their source revisions. Never count label seeds or duplicate implementations as independent dynamics. Zero observed hazards must not produce a zero-width safety claim.
