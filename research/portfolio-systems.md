## 1. universal-modder

**Implemented:** agent skills and engine playbooks, a Python CLI for bounded game/install fingerprinting, asset conversion, window/input tooling, snapshot/diff/restore, and worked game integrations. `um/scan.py` reads Steam/Epic/Xbox metadata and bounds directory indexing; this is actual tool code rather than only prompting. `um/backup.py` writes exclusive ZIP snapshots and per-file size/SHA-1 manifests, avoids same-second collisions and automatically backs up the target before restoration. Generated assets can require fal, Sprixen or Voidless credentials/services; local ComfyUI is another supported lane. The forthcoming mod hub is explicitly future work.

**Deep lesson for CROSSWIRE:** the Minecraft/GTA example has explicit transformations (one metre per block, axis permutation/reflection, yaw/pitch conventions), shared memory for colour/depth/overlay, WebSocket control/events and frame reprojection to hide latency. The Outer Wilds bridge contract is more revealing: its proposed yaw/pitch conversion is explicitly **unverified**, and the landmark oracle sends its pose directly in guest Minecraft coordinates. The authors correctly state that this checks the guest camera/frame but does not validate the host-to-guest mapping. A downstream oracle can pass while the adapter under study is bypassed. Include this exact assay failure as a synthetic negative control.

**Limits / overlap:** already covers cross-engine bridges and workflows for reading/reimplementing systems. A new modding assistant, generalized mashup toolkit or field-note store would be duplication. The source contract distinguishes verified behavior from planned protocol; do not treat every contract clause as implemented. Tested game/version dependencies are narrow. Independent execution was not performed.

**Pinned evidence:** [README](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/README.md), [package](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/pyproject.toml), [scan implementation](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/um/scan.py), [snapshot implementation](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/um/backup.py), [GTA passthrough](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/examples/minecraft-gta5-passthrough/README.md), [Outer Wilds interface contract and oracle limitation](https://github.com/rehan-remade/universal-modder/blob/c1dff21663665dd17af289744a301b66e369605e/examples/minecraft-outerwilds-passthrough/CONTRACT.md).

## 2. REA

**Implemented:** a local TypeScript CLI/MCP server with target-specific inspection adapters, process/browser observation, native decompiler bridges and structured provenance. Beyond recon, it already implements authenticated Evidence bundles, reconstruction coverage evaluation and deterministic reconstruction obligation ledgers. Closure considers selected boundaries, comparable original/verifier authority, required case kinds, owners, package coverage, contradictions, missing dependencies and residual unknowns. `reconstructionCoverageEvaluation.ts` evaluates missing/duplicate owners and authority routes; `reconstructionObligationLedgerIntegrity.ts` derives status/summary/graphs and a closure digest. Zero obligations returns unknown, and a passing inference-only verifier cannot become observed replay evidence.

**Deep lesson for CROSSWIRE:** preserve what was observed and what is still undecidable. Use comparable end-to-end authority: a local adapter unit test cannot close a behavioral composition claim. Keep failed calls in probe cost. Its analysis-efficiency experiments explicitly retain no-benefit timing/memory results, first-view costs and provider variation; optimization should be judged on the whole task.

**Limits / overlap:** a new generic evidence/claim ledger, reconstruction checklist, target inspector or broad MCP suite is already covered. REA's documented runtime and provider support varies by OS and target; Node >=22.19/24.11/26 is required, with native tools often additional. MIT on REA does not replace provider/bundled dependency terms. Existing source and documentation establish substantial implementation, but no release install was tested here.

**Pinned evidence:** [README](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/README.md), [version/runtime manifest](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/package.json), [coverage semantics](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/docs/reconstruction-coverage.md), [obligation semantics](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/docs/reconstruction-obligation-ledgers.md), [coverage evaluator](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/src/domain/reconstructionCoverageEvaluation.ts), [ledger integrity implementation](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/src/domain/reconstructionObligationLedgerIntegrity.ts), [measurement program](https://github.com/morluto/rea/blob/66aacc6fba7fb498302ca58894f179d77a847444/experiments/analysis-efficiency/README.md).

## 3. Odysseus

**Implemented:** self-hosted workspace for model-backed chat/agents, research, documents and personal tools; Python services/routes and browser frontend. The request-scoped turn contract is a substantial mechanism: deterministic capability classification, `required <= offered <= executable`, immutable schema copies, and dispatcher membership plus policy enforcement. It distinguishes capability selection from authorization and preserves tool-call/result identity and canonical rendering ownership. A small procedural-memory lifecycle module schedules retry review for user-owned skills (daily transient checks, weekly failed/needs-work repairs).

**Deep lesson for CROSSWIRE:** separate declared compatibility, available capability and successful execution. An adapter's selected contract does not make the downstream operation executable. Freeze the offered interface and retain identity across histories/replay. Explicit compound obligations prevent one successful suboperation from terminating a partially failed composition.

**Limits / overlap:** already occupies the broad local AI workspace, tool routing, memory and research-product space. Its roadmap still calls for installation/integration audits, slimmer prompts and degraded-state reporting. Turn classification is vocabulary based; its own contract warns that registration does not guarantee service health and some live verification remains unrun/blocked. A routing pass is not model understanding. Default branch is `dev`; README describes `main` as more curated. AGPL code reuse would need separate consideration; a clean independent toy research implementation can reuse the engineering lesson without copying its product.

**Pinned evidence:** [README](https://github.com/odysseus-dev/odysseus/blob/8877273e195a90d51bc6a37f3a1b60dc3414c431/README.md), [turn contract and limits](https://github.com/odysseus-dev/odysseus/blob/8877273e195a90d51bc6a37f3a1b60dc3414c431/docs/AGENT_TURN_CONTRACT.md), [actual routing/contract source](https://github.com/odysseus-dev/odysseus/blob/8877273e195a90d51bc6a37f3a1b60dc3414c431/src/turn_contract.py), [skill lifecycle](https://github.com/odysseus-dev/odysseus/blob/8877273e195a90d51bc6a37f3a1b60dc3414c431/services/memory/skill_lifecycle.py), [remaining work](https://github.com/odysseus-dev/odysseus/blob/8877273e195a90d51bc6a37f3a1b60dc3414c431/ROADMAP.md).

## 4. NexusFlow

Do not assume a thread count or common seed guarantees schedule-independent trajectories when shared state mutates; test that property explicitly if required.

**Limits / overlap:** a new universal prototype DSL, broad generated-tool suite or superficial portfolio combination repeats this repository. Science modules are explicitly coarse toy models; 3D support is metadata/scene export. README calls it experimental and recommends pinning tested patterns. ## 5. Flipper Zero Periodic NTAG Emulator

**Implemented:** five-file hardware application with a Furi GUI/timer/event queue, a random seven-byte UID prefixed by `0x04`, ISO14443-3A ATQA/SAK data, and NFC listener restart on a nominal ten-minute interval. The manifest requires `gui` and `nfc`; requirements contains unpinned `ufbt`. No README, licence or tests were present in the inspected tree.

**Deep lesson for CROSSWIRE:** its success count increments when a listener is allocated/started. It does not observe a reader handshake or verify NTAG213 memory/page commands. Distinguish construction, protocol acceptance and successful behavior with separate measures. Periodic tick events can be dropped if the queue is full; the countdown is an event count rather than an absolute monotonic deadline. Timing is part of the interface contract.

**Limits / overlap:** the repository name exceeds what the source establishes: inspected source is a lower-level ISO14443-3A UID listener configuration, not evidence of complete NTAG213 behavior or field-tested reader interoperability. Hardware required; not a CPU-local lab foundation. No copying without a clear reuse licence. There is no need for CROSSWIRE to interact with RFID hardware; model finite protocol states synthetically.

**Pinned evidence:** [entire core source](https://github.com/djpiper28/Flipper-Zero-Periodic-NTAG-Emulator/blob/98fd7478253f9041195adc8eedfa95eabe084aff/ntag213_rotator.c), [application manifest](https://github.com/djpiper28/Flipper-Zero-Periodic-NTAG-Emulator/blob/98fd7478253f9041195adc8eedfa95eabe084aff/application.fam), [build dependency](https://github.com/djpiper28/Flipper-Zero-Periodic-NTAG-Emulator/blob/98fd7478253f9041195adc8eedfa95eabe084aff/requirements.txt).

## 6. quibble-builds

**Implemented:** substantial C++ UEFI Windows bootloader source, NTFS/Btrfs and FreeType/HarfBuzz submodules, CMake toolchains and manually dispatched x86/amd64 build workflows. `boot.cpp` handles several Windows-version-specific loader-block/extension layouts. The amd64 workflow checks out the triggering SHA, builds Debug/RelWithDebInfo and uploads bootloader and filesystem drivers. This repository contains source rather than merely download links.

**Deep lesson for CROSSWIRE:** compatibility is a typed, versioned boundary: two modules may expose superficially similar layouts but differ in semantics, platform support and invariants. Treat format/version declarations as hypotheses with behavioral checks; preserve architecture and source revision in every adapter receipt. Isolate experiments from the host boot chain.

**Limits / overlap:** README calls it proof of concept and lists signature verification, ASLR, complete registry recovery, ARM and hibernation as unfinished. Build artifacts do not prove boot success. README's stated Windows coverage is XP–10 22H2, with firmware variation; it does not establish general current-Windows support. No bootloader install or hardware test was attempted. LGPL and component licences remain independent. CROSSWIRE should borrow typed compatibility and failure-state ideas, not modify real boot firmware.

**Pinned evidence:** [README](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/README.md), [version-sensitive boot source](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/src/boot.cpp), [build workflow](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/.github/workflows/build-amd64.yml), [submodule origins](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/.gitmodules), [CMake](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/CMakeLists.txt).

## 7. SVideo

**Implemented:** TypeScript/FFmpeg video-to-Scratch converter. It applies `mpdecimate`, scale/pad and a tile filter, stores many frames per costume, derives a frame look-back list from FFmpeg debug output, injects image/audio/frame-map fields into a Scratch project template and writes the resulting `.sb3` ZIP. Dependencies include FFmpeg/ffprobe binaries and archiver. README's prose says a default 30x30 grid while shown CLI defaults are 10x10: consult actual options/configuration rather than a loose description.

**Deep lesson for CROSSWIRE:** matching spatial content does not preserve temporal semantics. Duplicate suppression must carry an explicit repeat/duration map; delays, repeated observations, chunk boundaries and audio timing deserve separate conformance probes. Use deterministic synthetic sequences where exact decoded event order and duration are known. A representation's compression ratio is not the same as preserved task behavior.

**Limits / overlap:** no test script or test directory appeared in the inspected tree. Code reads only the first `drop_count` regex match per incoming stderr chunk; robustness to arbitrary logging chunk boundaries is unestablished. Existing media conversion itself is not novel. A CPU-local synthetic temporal-adapter assay is more focused than importing a video toolchain.

**Pinned evidence:** [README](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/README.md), [package/version](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/package.json), [filters and frame map](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/src/FFmpeg.ts), [Scratch injection](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/src/ProjectBuilder.ts), [conversion/archive orchestration](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/src/App.ts).

## 8. NEUROGRAFT

**Implemented:** CPU PyTorch research instrument with typed immutable source graphs, sparse recurrent encoders, learned cross-source top-k routing plus null route, human/all-source readouts, synthetic delayed XOR benchmark, matched controls, checkpoint replay, live synthetic navigation, observed-map/masked controllers, action-conditioned auxiliary prediction and v0.12 successor representation/reverse replay over experienced transitions. `dynamics.py` actually aggregates sparse relation messages and maintains separate learned overlays; source graph observations are not rewritten as learned edges. Optional frozen-Qwen adapters exist, but README explicitly states tiny random-model tests and no loaded/trained pretrained Qwen checkpoint.

**Evidence boundary:** OpenWorm is acquired with filtering receipts; fly/human demonstration modules remain fixtures. The early five-seed fixture benchmark reports 60% grafted vs 54.14% rewired; its exploratory interval includes no topology advantage. v0.10 reports 66.7% raw unassisted success for all-source plain residual vs 62.5% original human plain across repeated scenarios, not independent biological validation. Human-readout rotation augmentation falls to 41.7%, demonstrating that a plausible invariance transform need not improve measured behavior. v0.11's auxiliary predictor improves prediction error without improving reported expert-arm navigation success (both 7/16); task-specific learning and auxiliary accuracy must stay separate. v0.12 reports a 744-test pass and package parity; these were read, not rerun.

**Critical CROSSWIRE lesson:** the saved initial-observation audit covers 768 worlds with 53 distinct initial observations. Six observation groups (53 worlds) have conflicting fixed expert labels; two groups (eight worlds) have no common optimal first action. This is an explicit information limitation, scoped to initial observations rather than all histories. New interface work should elevate such ambiguity into calibrated abstention and active distinguishing probes, rather than train away an unidentifiable label.

**Limits / overlap:** another neural graft/routing layer, graph-memory ecology, learned navigation controller, symbolic map/SR planner or generic lesion/replay bench would repeat current capabilities. CROSSWIRE can be distinct by studying whether independent implementations can be behaviorally aligned under finite evidence, with competing mappings retained and composition rejected/abstained when unsupported. Keep adapter training separate from frozen evaluation, assisted from unassisted action metrics, same-weight interventions from separately trained baselines, and implementation receipts from empirical advantage. Source/data licensing is unresolved in the matrix; do not assume repository publication creates a permissive licence or that public datasets share code terms. The README and some reports contain older local-build/no-publication language despite the repository being live; the immutable current GitHub existence is directly verified, whereas these older statements are historical documentation.

## CROSSWIRE assessment

The distinct research question is **when finite behavioral evidence justifies composing independently implemented modules through an unknown interface, and when ambiguity requires abstention or another probe**. Routing, stitching and evidence recording are supporting machinery with existing portfolio overlap; the measurable mechanism should be uncertainty-preserving identification of interface maps and the decision to compose.

Use small CPU-local finite transducers with deliberately separate implementations and explicit hidden coordinate/action permutations, sign/scale conventions, bounded delay/repeat behavior and capability loss. Define a finite candidate class and maintain the version space of mappings consistent with observed calibration traces. An active probe seeks a behavioral disagreement among surviving mappings. Compose only when candidates agree on the requested behavior at the declared confidence/coverage boundary, then assess on sealed held-out traces and shifts. The oracle/true mapping is available to evaluation only, not calibration selection. Include genuinely aliased cases where calibration cannot distinguish two maps, cases where no permitted map exists, and changes after calibration.

Essential comparisons: identity/no adapter; forced best-fit adapter; uniform/random probes under the same budget; behavior-disagreement probe selection; exhaustive oracle mapping as an upper bound; and uncertainty ablated with mandatory composition. Pair all on identical modules, probe opportunities and held-out scenarios. Report harmful-transfer rate, accepted-composition coverage, selective risk, calibration/held-out discrepancy, distinguishability/query cost and drift detection delay. A method that avoids all harm by rejecting every composition has zero coverage and is not a useful success.

Do not claim impossibility from a finite failed search. In the bounded toy class, impossibility can be certified by exhaustive enumeration; outside that class use unresolved/incompatible-with-declared-class. Keep confidence about sampled held-out performance separate from exact version-space guarantees. Add the universal-modder-inspired bypassing-oracle negative control, the NTAG construction-versus-handshake distinction, SVideo temporal repeat tests and Quibble version/capability mismatch cases. These are a coherent interface research mechanism, not eight unrelated subsystems.

Prior-art novelty must still be assessed against functional model alignment/stitching and grounded stranger coordination. This reviewer did not independently assess the parent-specified ICML 2025 / June 2026 / October 2026 papers; avoid a first-of-kind claim until those primary sources are reviewed.
