# Live review: nine synthetic research laboratories

Reviewed 2026-10-22 through the connected GitHub plugin. For every repository, the repository URL, default-branch metadata, recursive tree, README, and listed core/config/result evidence were fetched live. Mnemorph was explicitly reviewed on main. No source checkout, process, model, dataset, or existing repository was changed. No tests or experiments were executed in this review: recorded results below are repository evidence, not fresh replication.

Memory was used only to locate likely mechanisms and past evidence; current SHA-pinned source and documents take precedence. The portfolio supports lessons about experimental software and synthetic mechanisms. It establishes no biological, consciousness, ecological, clinical, or general intelligence result.

## Per-repository findings

### 1. 3d-animal-simulator-Hybrid-Agent / EvoSim

**Implemented:** fixed 1/60-second ecological stepping; inherited traits, predators/prey, local learning; schema-7 complete snapshots; real simulation rollouts from a frozen live checkpoint; isolated observation RNG; imperfect local eDNA teaching observations; energy-aware hunting and local vegetation renewal. The experiment source restores the same state, applies the treatment, and resets a shared future stream. It explicitly recognizes that subsequent draw consumption can diverge. Sensor coverage is compared with hidden simulated local truth and is not statistical confidence.

**Evidence and limits:** package.json identifies 6.1.0. The checked-in comparison gives three matched 120-second seeds, initial-state hashes, and raw endpoints against 6.0 at a2ff130376be177f86cac59f845b326da59b3469. Submerged-starvation events change from 26/19/18 to 0/0/0, with predator survivors from 0/0/0 to 3/4/3. This tests the full rules update in three convenient worlds; it does not isolate one mechanism or establish ecological realism. The agent cap and short horizons bound conclusions. No tests were rerun here.

**Lesson:** deterministic state and separate observation noise make intervention and measurement errors inspectable. Equal seeds alone do not prove aligned later events.

**Avoid duplicating:** another seeded ecological sandbox, imperfect-observation dashboard, local learning/population lab, or paired conservation-intervention tool.

Sources: [README](https://github.com/kai9987kai/3d-animal-simulator-Hybrid-Agent/blob/b7dd934770380a28717ddc82e3dfa7f127732a75/README.md), [experiment implementation](https://github.com/kai9987kai/3d-animal-simulator-Hybrid-Agent/blob/b7dd934770380a28717ddc82e3dfa7f127732a75/src/experiments.js), [package/version](https://github.com/kai9987kai/3d-animal-simulator-Hybrid-Agent/blob/b7dd934770380a28717ddc82e3dfa7f127732a75/package.json), [raw 6.1 comparison](https://github.com/kai9987kai/3d-animal-simulator-Hybrid-Agent/blob/b7dd934770380a28717ddc82e3dfa7f127732a75/docs/benchmarks/v6.1-comparison.json).

### 2. GhostInTheMachine

**Implemented:** a synthetic recurrent network with action authorship, efference copy and a comparator; cross-yoked twins; lesions; multiple surrogate nulls; instrument calibration; locked analysis files; separate coded runs and unblinding keys; claims linked to result files. The v7 engine decomposes prediction error into a ridge-predicted state component and a residual, with separately replayable streams. This provides actual mechanistic interventions, beyond an observational dashboard.

**Evidence and limits:** the v7 summary labels its run confirmatory and reports a verifying lock; this review read the plan and result record but did not recompute lock verification or rerun the campaign. The prespecified exploratory meta-analysis pools eight samples / 360 synthetic networks: persistence difference +0.1389 nats, HKSJ interval [0.1247, 0.1530], 320/360 positive. The 72-network powered Ψ test is unsupported (mean 0.0322; interval [-0.0299, 0.0925]; p=0.154). The older emergent-self event is explicitly retracted, and specificity to the named self population was revised because the effect follows comparator wiring. These are synthetic architecture findings, not independently replicated biology or consciousness evidence. Distinct network samples are not independent implementations or outside laboratories.

**Lesson:** keep retractions and failed replication visible; use counterfactual stream substitution and calibrated nulls to turn broad proxy claims into a narrow mechanism.

**Avoid duplicating:** synthetic consciousness proxies, comparator-based agency, action authorship versus yoked-control persistence, or another claim-status ledger as the main contribution.

Sources: [README/claim table](https://github.com/kai9987kai/GhostInTheMachine/blob/239f5de6452f78f3960de07c393268eeac142d03/README.md), [v7 error decomposition engine](https://github.com/kai9987kai/GhostInTheMachine/blob/239f5de6452f78f3960de07c393268eeac142d03/src/ghost_v7/engine.py), [v7 result summary](https://github.com/kai9987kai/GhostInTheMachine/blob/239f5de6452f78f3960de07c393268eeac142d03/results/v7/SUMMARY_v7.md), [v7 preregistration](https://github.com/kai9987kai/GhostInTheMachine/blob/239f5de6452f78f3960de07c393268eeac142d03/prereg/PREREGISTRATION_v7.json).

### 3. GenesisEngine

**Implemented:** a regulatory genome develops an abstract multicellular hex-lattice phenotype; local morphogen and GRN updates, differentiation, springs, recurrent controllers, Hebbian/reward-modulated modes, energy, reproduction and ancestry. The source double-buffers local expression and records developmental history. CLI experiments, full RNG snapshots, local browser viewing and source-hashed receipts separate the core from rendering.

**Evidence and limits:** v0.1 documentation records 34 tests, browser checks, wheel install checks and a five-seed 300-tick learning example, whose generated outputs are excluded from Git. Those are historical software checks; the numerical research output was not available as a checked-in result in this tree. A direct-encoding comparator is explicitly deferred. Treatment is applied before embryogenesis; equal initial seeds can diverge after different RNG consumption. Predation, open-ended evolution and biological realism are not established.

**Lesson:** the fair baseline must actually implement the alternative representation. Relabeling the same developmental organism cannot answer direct versus indirect encoding.

**Avoid duplicating:** genome-to-body development, a generic artificial-life ecology, exact continuation snapshots, or developmental-versus-direct encoding as the new central question.

Sources: [README](https://github.com/kai9987kai/GenesisEngine/blob/a43099ef21e91b75b812e3eb883cb4f3813ab7c7/README.md), [development implementation](https://github.com/kai9987kai/GenesisEngine/blob/a43099ef21e91b75b812e3eb883cb4f3813ab7c7/src/genesis/development.py), [experiment implementation](https://github.com/kai9987kai/GenesisEngine/blob/a43099ef21e91b75b812e3eb883cb4f3813ab7c7/src/genesis/experiments.py), [validation record](https://github.com/kai9987kai/GenesisEngine/blob/a43099ef21e91b75b812e3eb883cb4f3813ab7c7/docs/validation.md).

### 4. FLY-DIAMOND-NEXUS

**Implemented:** World Lab planners and shared learned reward maps, Nexus neural sandbox, and a fly-inspired shared-connectome lab with separate per-agent registers. The source contains SixteenFlyBrainSyncytium and TwentyTwoFlyBrainSyncytium, six bounded heuristic roles (plume, climate, threat forecast, route memory, uncertainty, social), normalized coupling edits, expanded v8 snapshots and a browser selector choosing 16 or 22 modules. The 22-module source/HTML exists even though both READMEs and the measured circuit table still describe sixteen modules. The spiking LIF module is separate from the interactive controller; the included MaleCNS R material is not proof that the browser loads a biological connectome.

**Evidence and limits:** the recorded 40-seed comparison holds compass mechanism fixed: three non-compass upgrades give +22.95 net score, interval [-9.2, +56.0], inconclusive. The oracle-compass advantage is +145 score relative to estimating heading. A single AL brain scores 283.60 in a different 20-seed arm table versus 144.45 for 16 modules; the repository does not support a claim that more modules win. The table documents the earlier circuit benchmark, not a measured 22-versus-16 improvement. No fresh tests or benchmark were run. An inconclusive interval also does not prove zero cost/noninferiority, despite stronger wording in the documentation.

**Lesson:** reveal oracle information and mismatched sensory privileges in baselines; module count and biological names do not establish functional value. Shared state must not leak one agent's registers or credit assignment into another's.

**Avoid duplicating:** another connectome-inspired swarm, adding more specialist modules, odor navigation, or a localhost Supermix telemetry bridge.

Sources: [README](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS/blob/0c8d4100b21d8889bacdef1a9c6dfc20b3424242/README.md), [22-module source](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS/blob/0c8d4100b21d8889bacdef1a9c6dfc20b3424242/DIAMOND-SIM-FLY/src/fly-brain-engine.js), [browser module selection](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS/blob/0c8d4100b21d8889bacdef1a9c6dfc20b3424242/DIAMOND-SIM-FLY/fly-diamond-nexus.html), [22-module design and limits](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS/blob/0c8d4100b21d8889bacdef1a9c6dfc20b3424242/DIAMOND-SIM-FLY/docs/fly-lab-22-design.md), [measured comparisons](https://github.com/kai9987kai/FLY-DIAMOND-NEXUS/blob/0c8d4100b21d8889bacdef1a9c6dfc20b3424242/DIAMOND-SIM-FLY/docs/validation.md).

### 5. Causeway

**Implemented:** 52-week synthetic watershed with 12 growers, four policy packages, and four assumption lenses; user notes mapped to mechanisms; local exports and receipts. Source keys random draws by seed/week/actor/channel, so path divergence does not shift later weather or agent-choice draws. The sensitivity lenses change uptake, restoration response or entitlement gap one at a time. Paired intervals use mean ±1.96 standard errors.

**Evidence and limits:** v0.2.0 is expressly uncalibrated and bundles no field observations. The tree has no test or numerical benchmark/result files. The research note explicitly says it does not implement robust Bayesian experimental design/R-IDeA or full PROV-O, and has not established theoretical guarantees of the cited event-keying framework. Source notes are design references, not validated watershed observations. The lenses are hand-chosen scenarios without probabilities, not independent simulator implementations.

**Lesson:** source-to-assumption traceability plus event-keyed stochastic coupling is useful; provenance, sensitivity and calibration are different accomplishments.

**Avoid duplicating:** evidence library + synthetic agent world + paired policy scenario/sensitivity workbench. Merely adding more assumption lenses would be a continuation, not a distinct instrument.

Sources: [README](https://github.com/kai9987kai/Causeway/blob/e25ea9e6a5a70f60f5a6ee36756aceb3c6c9baac/README.md), [model and event keys](https://github.com/kai9987kai/Causeway/blob/e25ea9e6a5a70f60f5a6ee36756aceb3c6c9baac/src/model.js), [research-method boundaries](https://github.com/kai9987kai/Causeway/blob/e25ea9e6a5a70f60f5a6ee36756aceb3c6c9baac/docs/research-basis.md).

### 6. MOLT

**Implemented:** a cue-to-choice toy whose traces occupy either three head cells or nine body cells; head removal/regrowth, turnover, yoked graft and sham; paired/unpaired/reversed training; matched schedules; finite replenishing cohort food and energy. Source explicitly wipes indices 0–2 on head intervention and leaves body carriers intact; cells accumulate cue statistics, and readout averages retained carriers.

**Evidence and limits:** version 0.1.0 README documents reference MOLT-9DAA74B6: seed 82417, 24 matched seeds, head regrowth, 100% cue stability and noise 0.05. Accuracy 47.9% versus 90.4%, delta +42.5 points, descriptive bootstrap interval [+40.7, +44.3]. The result follows encoded carrier erasure/preservation assumptions. The reference is documented, not accompanied by a full checked-in per-event receipt; exports themselves are seed/exposure aggregates. The current tree has no automated tests or benchmark directory. This is neither planarian study replication nor biological memory evidence.

**Lesson:** make the causal answer encoded by the model explicit; a large effect in a toy world may demonstrate rules faithfully rather than discover a mechanism.

**Avoid duplicating:** memory placement after tissue loss/regrowth, distributed trace retention, cue stability reversal, grafts or another memory-ecology organism.

Sources: [README/reference result](https://github.com/kai9987kai/MOLT/blob/8ac04b1839b82d4e4d83166f1938bc6e1150197a/README.md), [carrier erasure/readout implementation](https://github.com/kai9987kai/MOLT/blob/8ac04b1839b82d4e4d83166f1938bc6e1150197a/src/engine.js).

### 7. MEMORY-CARRIER-OBSERVATORY

**Implemented:** four weighted trace channels (internal policy, body, habitat, colony), six transfer contexts, a 24-cell single-removal matrix, and a 96-cell all-subsets factorial. Per-seed inclusion-exclusion/Möbius coefficients decompose up to four-way effects; leave-one-pair-out means show influence. A probe suggestion ranks disagreement among five fixed hand-authored hypotheses. Source shows a noisy weighted vote, shared group trace, common decision draws and fixed carrier accuracy functions.

**Evidence and limits:** v0.4.0 is an exploratory instrument, not a learned biological memory system. The hypotheses never update from outcomes; the next-probe suggestion is not adaptive Bayesian learning. Normal-approximation intervals reuse observations across 90 nonempty subset terms and six contexts, with no multiplicity control. The leave-one-out range is an influence diagnostic, not replication. A timestamp field named preregisteredAt is created at run time and is not a cryptographically frozen prospective analysis plan. The recursive tree has no test or numerical result files. No quantitative effect is independently asserted here.

**Lesson:** full subset intervention maps expose nonadditivity hidden by one-at-a-time lesions; distinguish algebraic interaction, influence and confirmatory evidence.

**Avoid duplicating:** carrier-removal × transfer matrices, a memory-substrate atlas, factorial decomposition or a disagreement-ranked probe UI.

Sources: [README](https://github.com/kai9987kai/MEMORY-CARRIER-OBSERVATORY/blob/523c10b46fa26acd53cd8468f95d3cbf55011437/README.md), [complete simulator/decomposition/probe logic](https://github.com/kai9987kai/MEMORY-CARRIER-OBSERVATORY/blob/523c10b46fa26acd53cd8468f95d3cbf55011437/src/engine.js), [protocol and interpretation](https://github.com/kai9987kai/MEMORY-CARRIER-OBSERVATORY/blob/523c10b46fa26acd53cd8468f95d3cbf55011437/docs/EXPERIMENT_PROTOCOL.md).

### 8. Mnemorph (main)

**Implemented:** a hand-coded grid subject with five synthetic mechanism families; typed lesion/scramble/delay/regrowth/context-shift assays; matched saved subjects; expected-information-gain candidate selection; bounded revisable protocol grammar; independent withheld evaluator; replayable public receipts and separate auditor labels. Six methods include fixed one-factor/factorial, random equal budget, frozen grammar, adaptive grammar and an oracle diagnostic. Source scores candidates using information gain divided by operation/tick cost, with invalid/destructive penalties. Grammar revision adds successful observed protocols at completed batch boundaries.

**Evidence and limits:** the systems paper reports 114 tests and repeatable four-seed × five-family smoke output. This is documentation of software verification, not evidence adaptive selection wins. Confirmatory-template.json explicitly has locked=false, empty seeds/families, required sample size null and a placeholder assay hash; its instructions state the current runner cannot execute a confirmatory plan. Public snapshots expose wiring from which assignments can be inferred, although the runtime compiler is not directly given the snapshot or auditor label. Smoke auditor files exist; the reviewed smoke-final-d record contains 120 method/seed/family auditor rows. No confirmatory claim follows.

**Lesson:** separate pre-outcome predictions, assay acquisition, withheld scoring, direct data-flow isolation and secrecy. An executable smoke pipeline is not a completed powered study.

**Avoid duplicating:** adaptive assay generation, grammar revision for experiment design, mechanism identification after regrowth, or compiler-versus-frozen information-gain comparison in a single synthetic system.

Sources: [main README](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/README.md), [candidate/grammar compiler](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/src/core/compiler.js), [unlocked confirmatory template](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/configs/confirmatory-template.json), [verification paper](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/docs/paper.md), [example auditor output](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/output/smoke-final-d/auditor-evaluation.json).

### 9. TESSERA

**Implemented:** expression-tree evolution over a 4-bit two-input DSL; four arms (closed, snippet relay, one-lineage opcodes, ratified opcodes); exhaustive 256-case function certificates; publication requiring two independent single-founder lineages and two task families; inactive opcode expiry after two epochs. After acquisition, populations are discarded and fresh matched programs solve eight public unseen compositions with frozen learned vocabulary and equal population×generation slots. This is an implemented held-out composition phase, not merely proposed transfer.

**Evidence and limits:** v0.2.0 exploratory pilot: eight paired seeds, population 32, 18 generations. Frozen transfer accuracy is 28.50% closed versus 28.32% ratified, paired delta -0.18 points, descriptive interval [-0.53, 0.00]. One ratified opcode was admitted; the pilot does not support ratification benefit. Exact solutions are rare. The public fixed targets, shared DSL, finite truth domain and unequal primitive/wall-clock costs limit generalization. Its certificate proves finite-domain semantics, not external program safety or open-ended discovery.

**Lesson:** test useful transfer after discarding the acquired population, retain negative mechanism evidence, and count the actual admission/use bottleneck. A correct reusable representation need not improve search.

**Avoid duplicating:** program-library learning, independent rediscovery ratification, finite truth-table-certified shared opcodes, or transfer via a frozen discovered vocabulary.

Sources: [README](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/README.md), [engine/admission/transfer](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/src/engine.js), [pilot results and limitations](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/docs/DEVELOPMENT_PILOT.md), [package version](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/package.json).

## Distinct direction: behavioral interoperability with necessary abstention

A promising question outside these nine implemented centers is: **Can a module safely connect to an independently implemented module when sensor/action meanings, temporal alignment and invariances are hidden, and can it recognize when available behavior cannot identify a safe connection?**

This is the proposed CROSSWIRE direction. Its central mechanism should be an ambiguity-preserving adapter: retain the set of mappings consistent with calibration behavior, search for counterexamples that distinguish them, and connect only when every surviving mapping predicts compliance with a prespecified harm constraint. Freeze that decision before a separate held-out audit. Otherwise abstain, distinguishing insufficient identification from a demonstrably incompatible connection. A small domain should contain provably indistinguishable calibration cases whose action mappings require opposite decisions, making abstention an objective ground-truth requirement. Any safety claim remains conditional on the candidate set and evaluation world covering the true mechanism; hidden misspecification must be a failure arm, not silently excluded.

| Existing project | Existing object | CROSSWIRE boundary |
|---|---|---|
| Mnemorph | Select intervention programs to discriminate five memory mechanisms within one subject engine | Calibrate a connection between separately built black-box modules; score harmful transfer/coverage and ambiguity, not grammar-based assay prediction |
| Observatory | Remove known weighted carriers and decompose factorial outcomes | Infer unknown interface semantics and temporal relations; no carrier-vote lesion model |
| Tessera | Publish exact functions within one shared DSL/interpreter | Compose independently implemented modules without shared labels, interpreter, representation or invariance assumptions |
| Causeway | Compare policies across three parameter/sensitivity lenses | Test transport across genuinely independent implementations and unknown interface transformations, not more parameter lenses |
| Fly Lab / Supermix-style module composition | Hand-wired specialists with known sensory/action contracts | Detect unknown or incompatible contracts and refuse a harmful graft; extra modules are not the intervention |
| Ghost | Error-stream substitution inside a known recurrent architecture | Cross-module behavioral identification under interface ambiguity, rather than self-model dynamics |

The proposed work must distinguish identification from behavior prediction, training-world fit from held-out transport, harmless abstention from harmful confident connection, and representation similarity from functional interoperability. A useful first experiment compares label matching, representation-similarity/least-squares alignment, one-best behavioral alignment, and ambiguity-preserving counterexample testing under the same query and compute budgets. Report harmful connection rate, useful-connection coverage, held-out regret, calibration query count, and abstention on provably unidentifiable pairs. Include hidden permutations, sign/scaling ambiguities, lag, drift, mismatched invariances and impossible pairs, with independently authored held-out implementations. A single hand-coded source with renamed variables would not establish independence.

This is a portfolio-distinct research question and candidate mechanism, not a global novelty claim. Recent alignment, stitching and stranger-coordination work must constrain the design and comparisons. Actual novelty would depend on a more complete literature review and eventual empirical results. The repo review alone cannot establish performance.
