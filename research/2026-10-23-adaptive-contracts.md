# Adaptive contracts: research and portfolio update

Reviewed 23 October 2026. This is a targeted primary-source review for the next CROSSWIRE upgrade, not an exhaustive survey or a claim to have selected the globally best algorithm. Paper records, selected full-text sections, repository heads and source functions were checked live. The four portfolio repositories below were inspected through the connected GitHub tools at immutable commits; none was executed or independently benchmarked in this review. Recommendations are engineering inferences from those sources.

## The next falsifiable question

Can a deployment policy that branches on observed outputs safely complete more finite tasks than a single precommitted action word, under the same candidate family, public evidence, acquisition budget and deployment horizon?

The existing core intersects the survivors' accepted action words. That can reject a task even when one harmless action would reveal which safe continuation to choose. The cohesive extension is a bounded observation-contingent policy, with exact temporal models and a separately checked finite certificate. This is an application of established partial-observation synthesis, not a new invention of belief states, shielding or adapter synthesis.

## Proposed finite mechanism and verification obligations

1. **Belief support.** Track a set of candidate identities together with the state and output buffer implied by the shared action/observation history. Candidate identities alone are insufficient for memoization when the same candidate can occupy different states. Include remaining horizon and contract progress in any search key.
2. **Robust action.** Admit an action only if its next semantic output is nonhazardous under every current candidate. Rejecting only actions that are hazardous under *all* candidates is too weak. A delayed output can conceal a current semantic hazard, so use current semantic transitions for safety and buffered raw outputs for observation branches.
3. **Observation branches.** Partition the candidates by the next predicted raw output, then require a winning continuation for every nonempty branch. An observation outside this partition is an assumption violation and stops execution. Do not synthesize a continuation from the private target state.
4. **Termination.** Stop only when the current semantic trace is accepted for every candidate on that branch. Goal arrival and the decision to stop must be observable through the common history; privately choosing different stop times for indistinguishable candidates is invalid. Empty support is contradiction, never vacuous success.
5. **Independent certificate checker.** Given the public model, contract, declared family, public evidence and policy tree, rederive initial survivors and traverse every reachable branch. Check action bounds, exact branch completeness, horizon decrease, terminal goals and hazard freedom; reject missing branches, stale model/evidence identity, cycles and unsupported schema. The checker should not merely call the synthesis function and compare hashes.
6. **Claim boundary.** A passing check proves the specified property for the enumerated finite models under the implemented checker. It does not prove the true target belongs to that family, that anchors are correct, that the checker has no bugs, or that the task is safe outside the toy environment. Private semantic corruption should remain a negative control even when a certificate passes.

These are design obligations for the upgrade. Implementation and validation status must be reported by the build/test artifacts; this research note itself is not a receipt that they have been fulfilled.

## Exact temporal ambiguity

The source model currently supports static permutations and one-step delayed observations. A raw-transducer signature must include the delay buffer and its reset value, not only the reference state and permutation. Two models can agree on every short probe and disagree later. Conversely, models can have identical raw behavior but different semantic contract outcomes.

Construct each adapter's reachable raw transducer over `(reference_state, output_buffer)` for delayed models, minimize/refine it exactly, then canonicalize from the initial state. Compare complete canonical transducers for raw equivalence. Keep that comparison separate from contract equivalence and semantic identifiability. A bounded distinguishing search returning no witness proves only that none was found within the bound, unless the entire finite product graph has been exhausted.

## Validation that would support the mechanism

- A hand-auditable branching task where no common fixed word succeeds, but a safe informative first step enables different successful continuations. Include the dual control where the same raw observation hides incompatible required actions and no robust policy exists.
- A mixed-survivor action that is safe for one interpretation and hazardous for another. It must be blocked before any target step. Repeat with delayed observations to ensure the buffer cannot conceal current hazards.
- Certificate mutation checks: omitted output branch, altered action, false goal leaf, excessive depth, cyclic structure, wrong survivor list and changed public model/evidence. Corruptions must fail through semantic checks even when their digests are recomputed.
- Exhaustive small finite cases: compare synthesized policies with independently enumerated bounded policy trees, and compare temporal raw equivalence with exhaustive reachable product exploration. Random samples alone cannot establish exactness.
- Matched evidence ablation: fixed-word versus adaptive policy, with separate calibration calls, deployment calls, planner transitions, verification work and useful audited completion. Preserve failure and abstention outcomes. A larger search budget is a resource cost, not a free improvement.
- Frozen held-out implementations and semantic-corruption controls. Report model-verified coverage separately from privately audited safety and successful target execution.

No claim is made here about global novelty, superiority to full synthesis tools, biological validity, large neural models, or general real-world safety. The useful contribution to test is the measured value of conditional deployment and exact, inspectable evidence in this bounded interoperability laboratory.
